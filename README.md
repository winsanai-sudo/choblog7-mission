# 초블7기 미션완료 사이트

주니어/시니어 명단에서 이름을 선택하고 휴대폰번호로 참가자가 접속한 뒤, 1주차부터 5주차까지 미션1/미션2 완료를 제출하는 작은 웹앱입니다. 제출 데이터는 `data/db.json` 파일에 저장됩니다.

## 실행

Codex 번들 Node가 있는 경우:

```powershell
& "C:\Users\ryu\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" .\server.js
```

브라우저에서 `http://localhost:4173` 으로 접속합니다.

## 마스터 접속

기본 비밀번호는 `choblog7` 입니다.

다른 비밀번호로 실행하려면:

```powershell
$env:MASTER_PASSWORD="원하는비밀번호"
& "C:\Users\ryu\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" .\server.js
```

## 미션 규칙

- 미션1: 제출 기간 제한 없이 블로그 주소를 반드시 입력해야 합니다.
- 미션1 안내 문구: `적당한 길이의 본문 글 + 그림8장이상 + 지도`
- 미션2: 체류1분이상, 좋아요, 서이추, 비밀댓글을 모두 체크해야 제출 가능
- 같은 참가자가 같은 주차의 같은 미션을 다시 제출하면 `n주차 미션은 이미 제출 하였습니다` 메시지가 표시됩니다.
- 마스터 화면에서 참가자별 5주차 성공 수와 주차별 성공률을 볼 수 있습니다.
- 마스터 화면에서 현재 진행 주차를 설정할 수 있습니다.
- 현재 진행 주차보다 이전 주차 미션을 나중에 제출하면 빨간색 `늦은 제출` 표시가 붙습니다.
- 마스터 화면의 `링크 모음` 버튼 또는 `http://localhost:4173/links.html` 주소로 미션1 블로그 링크만 모아볼 수 있습니다.
- 마스터 화면의 `전체 초기화` 버튼으로 모든 참가자와 제출 데이터를 삭제하고 처음부터 다시 시작할 수 있습니다.
- 같은 주차의 미션1과 미션2를 모두 완료하면 폭죽 효과와 함께 `n주차 미션 성공!!` 메시지가 표시됩니다.

## 데이터 파일

실제 제출 데이터는 `data/db.json`에 저장됩니다. 이 파일에는 이름, 휴대폰번호, 블로그 링크가 들어가므로 GitHub에는 올리지 않도록 `.gitignore`에 추가했습니다.

처음 배포하거나 새로 시작할 때는 `data/db.example.json`을 참고하면 됩니다. 서버 실행 시 `data/db.json`이 없으면 자동으로 새로 생성됩니다.
